# 发布来源与验证边界

发布日期：2026-09-30（Asia/Shanghai）。这是一份脱敏的源码快照，不是私人部署备份，也不包含原始交接压缩包的 Git 历史。

- 网关来源：用户提供的 CellBridge 交接快照中的完整 Go 源码，以及实际用于 N1 的修复。
- 模块工具来源：CellBridge-mac 交接源码及本地 OpenWrt ADB shim 适配。
- 原快照未保留可验证的上游 Git commit，因此不冒充精确的 upstream commit；许可证和作者声明单独保留。
